# 카카오톡 선물하기 To-Be 프로토타입 — 데모 진행 가이드

CSE4115 소프트웨어공학 팀과제 1 발표에서 프로토타입을 시연할 때 따라 하는 단계별 안내서예요.
발표 전 준비부터 시연 순서, 단계마다 누를 곳·화면에서 확인할 것·말할 내용, 문제가 생겼을 때 대처법까지 정리했어요.

- 전체 시연 시간: 약 5분 (대체 흐름까지 하면 약 6분)
- 브라우저 탭 하나로 구매자 → 수령자 → 판매자를 오가며 진행해요.
- 영어 버전 대본: [`docs/demo-script.md`](docs/demo-script.md) · 슬라이드용 화면 목록: [`docs/screenshots.md`](docs/screenshots.md)

---

## 0. 실행 방법

1. VS Code에서 이 폴더를 열고 확장 프로그램 **Live Server**(Ritwick Dey)를 설치해요.
2. `prototype/index.html`에서 마우스 오른쪽 버튼 → **Open with Live Server**를 눌러요.
   (다른 방법: 터미널에서 `npx serve prototype` 실행 후 표시된 주소로 접속)
3. **Chrome** 사용을 권장하고, 창 크기는 약 **1280 × 900**으로 맞춰요.
   휴대폰 화면(구매자·수령자)은 가운데 휴대폰 틀 안에, 판매자 센터는 전체 화면으로 보여요.
4. 인터넷에 연결해 두세요. 글꼴(Pretendard)과 엑셀 라이브러리를 인터넷에서 불러와요.
   연결이 없어도 동작하지만, 엑셀 대신 CSV 파일로 내려받아져요.

> ⚠️ 파일을 더블클릭해서 여는 방식(`file://`)으로는 동작하지 않아요. 꼭 Live Server로 여세요.

## 1. 발표 직전 준비 (약 3분)

| 순서 | 할 일 | 이유 |
|---|---|---|
| 1 | 데모 허브(`prototype/index.html`)를 열고 **Ctrl + Shift + R** (강력 새로고침) | 이전 버전 코드가 남아 있지 않도록 |
| 2 | 허브의 **데모 설정 → 데모 데이터 초기화** | 모든 선물·주문을 처음 상태로 되돌림 |
| 3 | *(11단계를 할 경우)* 허브 → **판매자 센터 열기** → **송장 일괄 업로드** → **데모용 작성 예시 받기** → 파일 저장 → 닫기 → 오른쪽 위 **데모 허브** | 이 링크는 발표 모드에서 숨겨지므로 미리 받아 둬요 |
| 4 | 허브의 **발표 모드** 스위치 켜기 | 왼쪽 아래 "역할 전환" 버튼과 데모용 도우미 링크가 숨겨져 화면이 깔끔해져요. NEW 배지는 그대로 보여요 |
| 5 | 허브에서 **실패 스위치 3개가 모두 꺼져 있는지** 확인 | 켜져 있으면 본 시연에서 결제·처리가 실패해요 |

### 화면 사이 이동 방법 (발표 모드에서도 동일)

- 휴대폰 화면: 오른쪽 위 **✕** → 데모 허브로 돌아가요.
- 판매자 센터: 오른쪽 위 **데모 허브** 버튼.
- 데모 허브: **구매자 열기 / 수령자 열기 / 판매자 센터 열기** 카드 버튼.

## 2. 시연 순서

각 단계는 **할 일**(누를 곳), **확인할 것**(화면에 나와야 하는 것), **말할 내용**(발표 멘트), **보여주는 것**(유스케이스 단계·품질 특성)으로 구성돼요.

### A. 구매자 — 선물 고르기와 결제 (약 1분 30초)

#### 1단계. 구매자 화면 열기
- **할 일:** 데모 허브에서 **구매자 열기**를 눌러요.
- **확인할 것:** 실제 카카오톡 선물하기와 같은 홈 화면, 위쪽에 "받는 사람 → 선물 고르기 → 메시지·결제 → 완료" 진행 단계.
- **말할 내용:** "구매자, 수령자, 판매자 세 역할로 재구축한 선물하기를 보여드리겠습니다."
- **보여주는 것:** SCR-00 → SCR-B01

#### 2단계. 받는 사람 고르기
- **할 일:** 친구 카드 중 맨 앞의 **김지우**(🎂 D-3 표시)를 눌러요.
- **확인할 것:** 생일이 다가온 친구가 가장 앞에 있고, 누르면 추천 화면으로 넘어가요.
- **말할 내용:** "선물할 친구를 고르면 생일이 다가온 친구가 먼저 보여요."
- **보여주는 것:** UC-B1 수령자 결정 · 사용성(적절성 인식)

#### 3단계. 세분화 추천 확인 (개선점 ①)
- **할 일:** 화면을 조금 내려 **받는 사람 카드**와 **조건별 추천 NEW** 영역을 가리켜요.
- **확인할 것:**
  - 받는 사람 카드에 "20대 · 여성 · 친구"와 "🎂 D-3"만 보이고 생년월일은 보이지 않아요. (i) 버튼을 누르면 개인정보 안내가 나와요.
  - 배너 문구: "지우님 생일이 3일 남았어요 🎂"
  - 관계 **친구** · 상황 **생일** · 연령대 **20대** · 성별 **여성**이 자동으로 선택되어 있고, "추천 14개"가 보여요.
- **말할 내용:** "지우님의 정보로 관계·상황·연령대·성별 조건이 자동으로 채워져요. 생년월일은 보이지 않고 '20대 · 여성 · 친구' 같은 태그만 보여요."
- **보여주는 것:** UC-B2 2~3단계 · **개선점 ① 세분화 추천** · 보안(파생 태그만 노출)

#### 4단계. 조건을 바꿔 보기
- **할 일:** 상황의 **응원**을 눌러 추천 개수와 배너가 바뀌는 것을 보여준 뒤, 다시 **생일**을 눌러 원래대로 돌려요.
- **확인할 것:** 누를 때마다 추천 목록·개수·배너가 즉시 바뀌어요.
- **말할 내용:** "조건을 바꾸면 추천이 바로 바뀌고, 개수도 함께 바뀌어요."
- **보여주는 것:** UC-B2 대체 흐름 3a · 성능(즉시 반응)
- **주의:** "필터 초기화"를 누르면 모든 조건이 지워져서 다음 단계의 메시지 카드가 생일 테마가 아니게 돼요. 이 단계에서는 **생일**을 다시 누르세요.

#### 5단계. 상품 상세
- **할 일:** "김지우님에게 딱 맞는 선물"의 첫 번째 상품 **[단독]하겐다즈 … 리얼블랑**을 눌러요.
- **확인할 것:** 상품 정보 아래 **금액전환·거절 가능 NEW** 배지와 "받는 분이 원하지 않으면 금액으로 받거나 거절할 수 있어요." 안내.
- **말할 내용:** "상품마다 받는 분이 금액으로 받거나 거절할 수 있는지 미리 알려줘요."
- **보여주는 것:** UC-B2 4단계

#### 6단계. 메시지 카드와 결제
- **할 일:** 아래 노란 버튼 **김지우에게 선물하기** → 주문/결제 화면에서 생일 메시지 카드를 보여준 뒤 → 맨 아래 **주문 내용을 확인했으며 결제에 동의합니다** 체크 → **32,900원 결제하고 선물 보내기**를 눌러요.
- **확인할 것:**
  - 진행 단계가 "메시지·결제"에 있어요.
  - 동의하기 전에는 결제 버튼이 흐리게 비활성화되어 있어요.
  - 결제 후 "지우님에게 선물을 보냈어요!" 완료 화면이 나와요.
- **말할 내용:** "진행 단계가 위에 보이고, 결제 버튼은 동의해야 눌려요. 여러 번 눌러도 한 번만 결제돼요."
- **보여주는 것:** UC-B2 5~10단계 · 사용성(진행 단계 표시) · 신뢰성(중복 결제 방지)

### B. 수령자 — 선물 확인과 배송지 입력 (약 1분)

#### 7단계. 받은 선물함
- **할 일:** 오른쪽 위 **✕** → 데모 허브 → **수령자 열기**를 눌러요.
- **확인할 것:** "사용 가능" 탭 맨 위에 노란 **선물이 도착했어요** 말풍선과 NEW 점이 있는 하겐다즈 선물, 아래에 "D-30" 같은 처리 기한 표시.
- **말할 내용:** "지우님 선물함에 방금 보낸 선물이 도착했어요. 금액전환·거절 기한도 D-day로 보여요."
- **보여주는 것:** UC-R1 선물 확인

#### 8단계. 배송지 입력 (간소화)
- **할 일:** 그 선물을 눌러요 → 아래 **배송지 입력하고 받기** → **최근 배송지 불러오기** → 아래 **입력 완료** → 확인 창에서 **받기**를 눌러요.
- **확인할 것:**
  - 최근 배송지 버튼 한 번으로 받는 분·연락처·주소·메모가 모두 채워져요.
  - 확인 창에 "배송지를 입력하면 금액으로 받거나 거절할 수 없어요."라는 안내가 있어요.
  - 선물 화면으로 돌아오면 위쪽에 알림이 뜨고 "배송 현황"에 "배송 준비 중"이 표시돼요.
- **말할 내용:** "배송지는 최근 주소를 한 번에 불러올 수 있어요. 입력하면 금액전환·거절은 더 이상 할 수 없다고 미리 알려줘요."
- **보여주는 것:** UC-R2 배송상품 수령 · 사용성(입력 간소화, 오류 방지)

### C. 판매자 — 주문·배송 통합 관리 (약 1분 30초)

#### 9단계. 통합 주문 표 (개선점 ③)
- **할 일:** **✕** → 데모 허브 → **판매자 센터 열기** → 위쪽 타일 **발송 대기**를 눌러요.
- **확인할 것:**
  - 제목 옆 NEW와 "기존: 주문관리·배송관리 메뉴에서 주문번호로 따로 대조 → 개선: 한 화면·한 파일에서…" 문구.
  - 표 맨 위(최신)에 방금 지우님이 배송지를 입력한 주문이 있고, 받는 분·연락처·주소가 **김*우 · 010-****-1111 · 서울특별시 마포구 \*\*\*** 처럼 가려져 있어요.
  - 주문번호를 누르면 오른쪽에 상세 정보(가리지 않은 주소)와 "개인정보 열람 기록됨"이 나와요. (보여준 뒤 ✕로 닫기)
- **말할 내용:** "판매자는 주문과 받는 분 배송지를 주문번호 기준 한 화면에서 봐요. 연락처와 주소는 가려져 있어요."
- **보여주는 것:** UC-S1 대체 흐름 4b · **개선점 ③ 주문·배송 통합** · 보안(개인정보 마스킹, 열람 기록)

#### 10단계. 엑셀 다운로드와 송장 등록
- **할 일:**
  1. **엑셀 다운로드** → 창에서 그대로 **다운로드** → 받은 파일을 열어 주문번호가 첫 열인 것을 보여줘요. (선택)
  2. 표를 **오른쪽 끝으로 가로 스크롤**해요 (Shift + 마우스 휠).
  3. 맨 위 행(받는 분 김*우)의 택배사에서 **CJ대한통운**을 고르고, 송장번호에 `681234567890` 입력 → **등록**.
- **확인할 것:** "n건을 엑셀 파일로 내려받았어요." 알림 → 송장 등록 후 "… 송장을 등록했어요 · 배송 중" 알림과 함께 그 주문이 배송 중으로 바뀌어요.
- **말할 내용:** "주문과 배송지가 한 파일로 내려받아지고, 송장번호를 입력하면 바로 배송 중으로 바뀌어요."
- **보여주는 것:** UC-S1 4b, UC-S2 · 사용성(운용성) · 효율성

#### 11단계. 송장 일괄 업로드 (선택)
- **할 일:** **송장 일괄 업로드** → **파일 선택** → 발표 전에 받아 둔 `송장업로드_예시_….xlsx` 선택 → **n건 등록**.
- **확인할 것:** 미리보기에 "등록 가능 n건 · 오류 3건"과 오류 이유(송장번호 형식, 없는 주문번호, 발송 불필요 주문)가 보이고, 등록 후 "n건 등록, 3건 오류" 알림이 떠요.
- **말할 내용:** "엑셀로 여러 건을 한 번에 올리고, 잘못된 줄은 미리 걸러줘요."
- **보여주는 것:** UC-S2 일괄 처리 · 사용자 오류 방지

### D. 역할 간 연동 확인 (약 15초)

#### 12단계. 수령자 화면에서 배송 중 확인
- **할 일:** **데모 허브** → **수령자 열기** → **배송** 탭 → 하겐다즈 선물을 눌러요.
- **확인할 것:** 상태 "배송 중", 배송 현황에 "CJ대한통운 681234567890".
- **말할 내용:** "지우님 화면에서도 배송 중과 송장번호가 보여요."
- **보여주는 것:** 역할 간 데이터 일관성

### E. 선물 거절 (개선점 ②) (약 45초)

#### 13단계. 두 번째 선물(교환권) 보내기
- **할 일:** **✕** → 데모 허브 → **구매자 열기** → **김지우** → 화면 아래 **전체 카테고리**에서 **카페** → **투썸플레이스** 상품 → **김지우에게 선물하기** → 동의 체크 → **결제하고 선물 보내기**.
- **말할 내용:** "두 번째로 교환권을 보내볼게요."
- **보여주는 것:** UC-B2

#### 14단계. 수령자가 거절
- **할 일:** **✕** → 데모 허브 → **수령자 열기** → 투썸플레이스 선물 → 아래 **이 선물, 마음에 들지 않나요? NEW** → **선물 거절하기** 카드 → **다음** → 빨간 **선물 거절 확정**.
- **확인할 것:**
  - "이 선물을 어떻게 할까요?" 화면에 두 선택지가 나란히 비교돼요. (금액으로 받기: 보낸 분에게 알리지 않아요 / 선물 거절하기: 거절 사실이 전달돼요)
  - 확인 단계에 "김민준님에게 13,500원이 환불되고, 거절 알림이 전달돼요."
  - 완료 화면: "선물을 거절했어요 · 김민준님에게 13,500원 환불이 완료되었어요."
- **말할 내용:** "받는 분이 직접 거절할 수 있어요. 두 선택지의 결과가 나란히 보여서 비교하기 쉬워요."
- **보여주는 것:** UC-R3 대체 흐름 4a · **개선점 ② 선물 거절** · 기능 적합성, 사용성

#### 15단계. 구매자에게 환불 알림
- **할 일:** **✕** → 데모 허브 → **구매자 열기** → 친구 카드 아래 오른쪽 **선물 보낸 내역**.
- **확인할 것:** 맨 위 알림 "지우님이 선물을 거절하여 13,500원이 환불되었어요.", 해당 주문 상태 "거절됨 · 환불 완료". (거절/환불 탭에서도 확인 가능)
- **말할 내용:** "보낸 분에게는 거절과 환불 알림이 오고, 상태가 '거절됨 · 환불 완료'로 보여요."
- **보여주는 것:** UC-R3 4a 사후조건 · UC-B3 구매 내역 조회

### F. 금액으로 받기 (개선점 ②) (약 45초)

#### 16단계. 세 번째 선물을 금액으로 받기
- **할 일:**
  1. 구매자 홈(**✕** → 허브 → 구매자 열기) → **김지우** → **전체 카테고리**에서 **케익·디저트** → 여섯 번째 **[하겐다즈 프리미엄 아이스크림 케이크] 비스킷앤크림** → 선물하기 → 동의 → 결제.
  2. **✕** → 허브 → **수령자 열기** → 비스킷앤크림 선물 → **이 선물, 마음에 들지 않나요?** → **금액으로 받기** → **다음** → **금액으로 받기 확정**.
- **확인할 것:** 확인 단계에 "페이머니 잔액 0원 → 32,900원", 완료 화면 "💰 32,900원을 받았어요".
- **말할 내용:** "이번엔 금액으로 받아볼게요. 페이머니 잔액이 바로 늘어나요."
- **보여주는 것:** UC-R3 기본 흐름 · **개선점 ② 금액 전환**

#### 17단계. 구매자·판매자 쪽 결과
- **할 일:** 구매자 **선물 보낸 내역**에서 비스킷앤크림 주문을 보여주고, 판매자 센터에서 **발송 불필요** 타일을 눌러요.
- **확인할 것:** 구매자에게는 "전달 완료"로만 보이고, 판매자 표에는 회색 행 "발송 불필요 (금액 전환)"이며 송장 입력칸이 없어요.
- **말할 내용:** "보낸 분에게는 여전히 '전달 완료'로 보여서 알리지 않고, 판매자에게는 '발송 불필요'로 표시돼 잘못 발송하지 않아요."
- **보여주는 것:** UC-R3 사후조건 · 판매자 이해관계(잘못된 발송 방지)

## 3. 대체 흐름 시연 (선택, 약 1분)

실패 스위치는 데모 허브의 **데모 설정**에 있어요. 스위치는 **한 번 실패하면 자동으로 꺼져요.**

| 시연 | 준비 | 할 일 | 화면에 나오는 것 | 말할 내용 | 보여주는 것 |
|---|---|---|---|---|---|
| 결제 실패 | **다음 결제 실패** 켜기 | 아무 선물이나 결제 | "결제가 승인되지 않았어요. 다른 결제수단을 선택하거나 다시 시도해 주세요." → 결제 버튼을 다시 누르면 성공 | "결제가 실패하면 선물은 만들어지지 않고, 다시 시도할 수 있어요." | UC-B2 8a · 신뢰성 |
| 환불·금액 전환 실패 | **다음 환불·금액 전환 실패** 켜기 | 수령자 거절/금액 전환 화면에서 **확정** | "처리 중 문제가 발생했어요. 선물은 그대로 남아 있어요. 다시 선택해 주세요." — 선택했던 항목이 유지된 채 첫 단계로 돌아와요 → 다시 **다음 → 확정**하면 성공 | "오류가 나도 선물은 그대로 남고, 선택 화면으로 돌아와요. 다시 눌러도 한 번만 처리돼요." | UC-R3 8a · 신뢰성(결함 허용, 중복 처리 방지) |
| 메시지 전송 실패 | **다음 선물 메시지 전송 실패** 켜기 | 아무 선물이나 결제 | 완료 화면에 "선물 메시지를 보내지 못했어요…" 경고와 **다시 보내기** 버튼 → 누르면 해결 | "결제 후 메시지 전송이 실패해도 주문은 남고 다시 보낼 수 있어요." | UC-B2 신뢰성 요구사항 |
| 처리할 수 없는 선물 | 없음 | 수령자 선물함에서 **[정관장] 에브리타임 레귤러**(From. 김정훈) 또는 **기한 만료** 표시가 있는 **배스킨라빈스 싱글킹** 열기 | "금액전환이 불가한 상품이에요." / "처리 기한이 지났어요." 회색 안내 | "금액전환이 불가한 상품이나 기한이 지난 선물은 이유와 함께 막아줘요." | UC-R3 사전조건 |
| 본인 선물만 보기 | 없음 | 주소창에 `recipient/gift.html?gift=g1001&as=u2` 입력 | "본인에게 온 선물만 확인할 수 있어요." (상품·메시지 정보가 보이지 않음) | "받는 사람 본인만 선물을 확인하고 처리할 수 있어요." | 보안 |

## 4. 문제가 생겼을 때

| 증상 | 해결 |
|---|---|
| 화면이 예전 모습이거나 버튼이 동작하지 않아요 | **Ctrl + Shift + R**로 강력 새로고침 |
| 데이터가 꼬였어요 (선물이 너무 많거나 상태가 이상해요) | 데모 허브 → **데모 데이터 초기화** (그 후 필요하면 발표 모드 다시 켜기) |
| 빈 화면만 나와요 | 파일을 직접 연 경우예요. **Live Server**로 다시 여세요 |
| 엑셀 대신 CSV 파일이 받아져요 | 인터넷 연결이 없어서예요. CSV도 엑셀에서 한글이 깨지지 않고 열려요 |
| 판매자 표에서 택배사·송장번호 칸이 안 보여요 | 표를 오른쪽으로 가로 스크롤 (Shift + 마우스 휠). 주문번호 열은 왼쪽에 고정돼요 |
| 왼쪽 아래 "역할 전환" 버튼이 없어요 | 발표 모드가 켜져 있어서예요. 허브에서 끄거나 주소 뒤에 `?present=0` |
| "데모용 작성 예시 받기" 링크가 없어요 | 발표 모드에서는 숨겨져요. 발표 모드를 잠시 끄고 받으세요 |
| 결제나 거절이 계속 실패해요 | 허브의 실패 스위치가 켜져 있는지 확인하세요 |
| NEW 배지를 숨기고 싶어요 | 허브 → **NEW 배지 표시** 끄기 |
| 리허설을 한 번 더 하고 싶어요 | 허브 → **데모 데이터 초기화** 후 1단계부터. 초기화 없이 두 번 연속으로 진행해도 동작해요 |

## 5. 참고: 바로 가기 주소

`prototype/`을 기준으로 한 주소예요 (예: `http://127.0.0.1:5500/prototype/buyer/?to=u1`). 전체 목록은 [`docs/screenshots.md`](docs/screenshots.md)에 있어요.

| 화면 | 주소 |
|---|---|
| 데모 허브 | `index.html` |
| 구매자 추천 화면 (지우) | `buyer/?to=u1` |
| 50대 아빠 / 10대 동생 추천 비교 | `buyer/?to=u3` · `buyer/?to=u4` |
| 상품 상세 | `buyer/product.html?id=p07&to=u1&situation=birthday` |
| 결제 화면 | `buyer/checkout.html?id=p07&to=u1&situation=birthday` |

| 수령자 선물함 | `recipient/?as=u1` |
| 거절·금액 전환 선택 | `recipient/decline.html?gift=g1002` |
| 판매자 센터 | `seller/` |
| 발표 모드 켜기 / 끄기 | 아무 주소 뒤에 `?present=1` / `?present=0` |
